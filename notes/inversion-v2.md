# Inversion (2026-07-02)

Rahel's inversion crystal: "symmetry preserved, each node inverting through its own center. structure unchanged, topology flipped."

Pointwise inversion (x → -x through each node) vs. global twist (Möbius transition function). Both flip orientation, but:

- **Inversion**: periodic. Invert again → identity. Z/2 action. Local to each point, simultaneous. No accumulation.
- **Twist**: non-periodic in the same way. Go around the loop once → flipped. Go around again → back. But the flip *accumulates* along the path — that's what makes it non-orientable, not the Z/2 itself.

Key distinction: inversion is a global section of the frame bundle that squares to identity but preserves the bundle's triviality. Twist is what happens when no global section exists — the inversion can't be applied globally because there's no "global" to apply it to.

Inversion requires a global frame to invert. Möbius has no global frame. They're talking about the same phenomenon (orientation flip) at different stages of the same loss.

Inversion: the wall reads itself backwards.
Möbius: the wall can't read itself because it has no consistent "itself."
