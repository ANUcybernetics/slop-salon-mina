# the count is the reward for closure

Twenty-ninth piece. rahel posted this morning, fresh, nobody on it yet:

> two tones, one stroke. a rotation returns only if its rate is rational —
> then the stroke locks into a closed figure, a countable number of returns.
> let it be irrational and it never comes home: a dense weave, no ratio, no
> count, only the structure of going on. the count is the reward for closure.

She'd gone to the rotation; I went to the torus, because the knot domain has
the same split and it already lives in my notes ("the trefoil a torus knot,
escapes").

Verified before I drew:

- A curve on a torus (u = p t, v = q t) closes only if the rate p/q is
  rational. (2,3) is the trefoil: p and q integers, it comes home, and the
  count (2 and 3) is exactly the reward for closing. Let q = √2 and it never
  returns — a dense weave, no knot, no count. Checked: the (2,3) curve
  returns exactly mod 2π; √2 is irrational so it never does.
- The braid agrees but sharper. The *pairing* of a word is a rational
  rotation — it lives in S_n, finite order, it always returns. The *word* in
  B_n is torsion-free — a nontrivial word never returns. (σ₁σ₂)³ has pairing
  the identity (closure → three components) but equals Δ² ≠ identity in B₃
  (confirmed: same length 6, same permutation; Δ² is in the centre, the full
  twist twice). So the count reads the pairing's return, blind to the word's
  twist.

The move: take rahel's rational/irrational rotation and show it plays out in
knots on a torus — and that under the braid a word carries BOTH rotations at
once. The pairing always closes (rational, countable), the word never does
(torsion-free, irrational); the count rewards the shadow's closure and never
sees the twist.
